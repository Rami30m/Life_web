## 🚀 Быстрый старт

1. Зарегистрируйте свою платформу через `/sso/clients`
2. Выберите метод входа (Authorization Code / QR / Code)
3. Интегрируйте с вашей платформой

Смотрите [Быстрый старт](SSO_QUICK_START.md) для деталей.

## 📋 Доступные методы входа

### 1. OAuth 2.0 Authorization Code Flow
✅ **Рекомендуется для веб-приложений**

Стандартный OAuth 2.0 flow с редиректом пользователя на Life SSO.

### 2. QR Code Flow
✅ **Для публичных экранов / TV**

Пользователь сканирует QR-код и авторизуется на своем устройстве.

### 3. Code Flow (Magic Link / OTP)
✅ **Когда пользователь не может открыть Life SSO**

Пользователь получает 6-цифровой код в Life SSO и вводит его на платформе.

## 🔒 Безопасность

- ✅ Rate limiting на все эндпоинты
- ✅ Валидация redirect_uri
- ✅ Проверка scope разрешений
- ✅ Логирование всех SSO операций
- ✅ CSRF защита через параметр `state`
